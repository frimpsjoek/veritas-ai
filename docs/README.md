# Veritas AI documentation

Veritas is an open-source research assistant you can check. It reads your papers, notes and Zotero library, answers
with citations you can open, and brings you a daily reading radar of the new papers that matter to you. It runs on
your own computer.

| [Reading radar](guide/reading-radar.md) | how the daily digest finds papers, sources and feeds, likes and dislikes |
| [Chat](guide/chat.md) | asking questions, sources, citations, models |
| [Connectors and MCP](guide/connectors.md) | literature tools (Valency Bond and others), using your library from Claude or ChatGPT |
| [Zotero and Obsidian plugins](guide/plugins.md) | installing and using the plugins |
